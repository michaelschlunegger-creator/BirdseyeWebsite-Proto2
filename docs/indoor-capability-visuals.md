# Indoor capability refresh

Scope: the Indoor Inspection overview and its Visual & Thermal, SLAM, Ultrasonic Thickness and Radiation capability pages. Prototype 1 and other page layouts are unchanged.

- Added top and bottom links returning to the overview's `#capabilities` anchor.
- Increased the overview's capability headings to bold, larger type.
- Added a low-opacity official Elios 3 flight illustration behind the overview content. Opacity is controlled in CSS; the source image is unchanged.
- Replaced the four generic capability layouts with compact layouts using official Flyability product imagery and demonstration outputs. Existing service descriptions and deliverables are retained.
- Added links between the four capabilities and retained relevant outdoor / digital-engineering connections.
